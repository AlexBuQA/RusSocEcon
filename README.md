# Анализ и прогнозирование социально-экономических показателей регионов России

Итоговый проект по дисциплине «Временные ряды».

**Показатель:** фактическое конечное потребление домашних хозяйств на душу населения
по субъектам РФ, 2000–2023 гг., в текущих рыночных ценах (рублей).
Источник: Росстат, файл `data/rsdocs_1491005410458_wide_appendix_2025.csv`.

**Автор:** Александра Бужор, Telegram: [@Angry_C_F_O](https://t.me/Angry_C_F_O)

## Что делает проект

1. Загрузка и подготовка данных (широкий → длинный формат, очистка пропусков,
   исключение агрегатов и территорий с неполными рядами: 96 записей → 79 регионов).
2. Кластеризация регионов по признакам динамики временных рядов
   (иерархическая кластеризация Ward, сравнение с K-means по silhouette score).
3. Выбор трёх репрезентативных регионов (по одному из каждого кластера).
4. Анализ рядов: тренд (скользящее среднее, фильтр Ходрика–Прескотта),
   тест Дики–Фуллера, ACF/PACF.
5. Прогнозирование: Holt, ARIMA (автоподбор порядков по AIC),
   бейзлайн NaiveForecaster (sktime); метрики RMSE/MAPE; rolling forecast
   для оценки устойчивости; прогноз на 2024–2026 гг.
6. Анализ ошибок (топ-5 по каждому региону, привязка к экономическим событиям).
7. Индивидуальные рекомендации по регионам на основе цифр прогноза.
8. Выводы и ограничения исследования.

## Запуск локально в VS Code

1. Установите Python 3.10+.
2. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <ссылка-на-репозиторий>
   cd time-series-regions-rf
   ```
3. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv .venv
   # Windows: .venv\Scripts\activate
   # Linux/macOS:
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
4. Откройте папку в VS Code, установите расширения **Python** и **Jupyter**.
5. Откройте `notebooks/final_project_time_series.ipynb`, выберите интерпретатор
   из `.venv` (кнопка выбора ядра справа вверху) и выполните все ячейки
   (**Run All**). Графики и таблицы сохранятся в `results/`.
6. Соберите письменный отчёт:
   ```bash
   python src/build_report.py
   ```
   Отчёт появится в корне проекта: `Отчёт_по_проекту.docx`.
